# MATLAB Code for EEG Analysis of Visual Categorization Across Contrast Levels

## Overview

This repository contains MATLAB scripts used for EEG data processing, decoding analysis, visualization, and statistical analysis in a study investigating visual categorization across different image contrast levels.

## Repository Contents

- **`Script0_reading_data_and_events`**: Reads the EEG data and associated event information.
- **`Script1_Preprocessing`**: Performs EEG preprocessing before subsequent analyses.
- **`Script2_decoding_animal_per_contrasts`**: Performs decoding analysis for animal categorization across different contrast levels.
- **`Script3_plot_decoding_journal_style`**: Plots the decoding results in a publication-ready format.
- **`get_sig_stats`**: Supporting MATLAB function for statistical analysis.

## Requirements

MATLAB, eeglab 2022 and later
